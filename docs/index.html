Telas

O que tem por baixo

  • Posição fracionária. Mover um cartão grava só a linha dele, sem renumerar a coluna.
  • Histórico por callbacks. Toda mudança vira um evento com o autor.
  • Busca segura. LIKE com ESCAPE explícito; % e _ não viram curinga.
  • Markdown seguro. Redcarpet com filter_html e sanitize.
  • Permissões no servidor. O leitor recebe 403 mesmo forçando a requisição.
  • Migração do legado. Converte o banco antigo, com teste sobre o formato original.

Rodar na sua máquina

O Prumo é uma aplicação Rails com banco SQLite, então precisa de um servidor e não roda no GitHub Pages. Com Ruby 4.0.9:

git clone https://github.com/PedroMaxis/ProjectMGMT
cd ProjectMGMT
bin/setup --skip-server   # gems, banco e dados de demonstração
bin/rails server          # http://localhost:3000

Na tela de entrada há login de demonstração com um clique (Marina é admin, Helena é leitora). A senha dos usuários do seed é prumo123.
